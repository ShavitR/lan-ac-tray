# Security policy

## Reporting a vulnerability

Please use **Report a vulnerability** on this repository's Security page to send a private report. Do not open a public issue with exploit details, packet captures, device identifiers, or network addresses.

LAN AC Tray sends local network discovery and control messages to paired devices. It does not send device data to a vendor cloud service. A report should explain the affected version, impact, and steps to reproduce while avoiding unrelated personal or network information.

For ordinary bugs and compatibility requests, use the public issue forms and redact local IP addresses, MAC addresses, Wi-Fi network names, and device IDs.
